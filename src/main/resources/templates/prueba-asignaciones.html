3. Procesar solicitudes pendientes

4. Reintentar solicitudes pendientes

Vuelve a buscar espacios disponibles para las solicitudes que todavía no tienen un espacio asignado. Si no encuentra uno compatible, la solicitud permanece pendiente.

5. Proponer una asignación alternativa

Si una solicitud continúa pendiente, el administrador puede proponer otro espacio, otros días o un horario diferente. La solicitud original no se modifica.
